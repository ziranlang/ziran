# Ziran check consolidation

## Baseline and measurement

The baseline is 286 check-runner entries, including 265 top-level shell scripts
and 21 direct entries. `make check` also runs `startup-graph-test` before the
runner. `assembly.mk` adds `zx-tools` prerequisites to `make check`.

An earlier successful 10-job run executed all 286 checks in 190.3 seconds
with zero reused. Individual times below come from that run and are elapsed
seconds under concurrent execution. The runner's elapsed time excludes the
Makefile's build prerequisites and startup graph test. The lexer cut's
complete `make check CHECK_JOBS=10` took 213.641 seconds on this host,
including 213.4 seconds in the runner. With the consolidated suite and build
prerequisites ready, the same command took 183.636 seconds, including 183.4
seconds in the runner. All 270 entries executed and passed with zero reused.
`make check-bootstrap` reproduced the checked-in Linux, Darwin and SIMD seeds.

The local run skipped the ARMv7 assembly feature runs, the Emscripten file-tree
case and the Android thread cross-links. The assembly comparison reported its
new-native ZX cell unavailable. The Vorbis check decoded its fixtures without
the optional Xiph header comparison. Both Unicode generators also passed in a
separate 11.8-second run with the pinned Unicode 17 data.

The remaining entries below are inventoried by area. Their related cases within
an area may have distinct inputs, outputs, backends or operating systems. A cut
adds the removed names and exact replacement coverage here before deleting them.

These replacements take the runner from 286 to 270 entries. The final inventory
contains 219 shell entries, 49 Ziran entries and two native entries. The startup
graph, bootstrap comparison, platform jobs and sanitizer gate keep their
existing invocations. The symlink regression extends the existing
`package_map_concurrency.sh` entry and runs in both forms of its map writer fixture.

`unicode_conformance.zi` keeps all 8,323 original cases in the same order,
including 1,585 folds, 1,488 lowercase mappings, 1,507 titlecase mappings and
3,743 property probes. The generator writes independent input and expected
UTF-8 bytes or scalar/flag rows and runs them through two shared loops. An
independent comparison decoded the emitted cases and matched each original
assertion. The Unicode standard-library data regenerated byte for byte.
