Get started / First program

Write your first Ziran program.

Build the current toolchain from source, write a complete program, then run it locally. Ziran is experimental; checked and portable formats can change between versions.

On this pageBuild the toolsWrite a moduleCheck and runContinue learning

01 / Prepare

Build the tools

Clone Ziran and build the tools. You need a C compiler and make. Go is needed only when compiling generated Go output.

git clone https://github.com/ziranlang/ziran.git
cd ziran
make

To run the project’s tests, use make check. Prebuilt downloads are not available yet.

02 / Source

Write a module

Save this as hello.zi. A source file is a module named after its filename.

main :: () {
    print("Hello, World!\n");
}

print substitutes each % in its format with the next argument, so print("Hello, %!\n", name) greets any name. Write %% for a percent sign.

Download hello.zi ↓

03 / Check and execute

Run the checked program

build/bin/ziran check --root . hello.zi
build/bin/ziran bundle --root . --entry hello:main -o hello.zib hello.zi
build/bin/ziran run hello.zib

The last command prints Hello, World!. To save checked IR, use build/bin/ziran ir --root . -o out hello.zi. Native output uses build/bin/ziran build --target=c, --target=cpp, or --target=go with the usual root and output options.
