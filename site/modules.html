Modules and packages.

138 standard modules and 19 packages, listed from the source on every site build. Each page shows the public declarations ziran api reports, with the comment written above them.

Stable ships in the latest release, v0.9.0 (for a package: it has a tagged release). In progress exists only on master or has no release yet.

Standard library

Import a module with #import "std/NAME". Modules ending in _linux, _windows or _go build only for that target. A module that needs a host capability runs in a portable bundle only when the program hosting the bundle binds it. 137 of 138 modules shipped in the latest release.
