Modules and packages.

93 standard modules and 14 packages, listed from the source on every site build. Each page shows the public declarations ziran api reports, with the comment written above them.

Stable ships in the latest release, v0.3.1 (for a package: it has a tagged release). In progress exists only on master or has no release yet.

Standard library

Import a module with #import "std/NAME". Modules ending in _linux, _windows or _go build only for that target. A module that needs a host capability runs in a portable bundle only when the program hosting the bundle binds it. 73 of 93 modules shipped in the latest release.
