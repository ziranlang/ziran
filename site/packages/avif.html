AVIF

Optional, headless Ziran image package. Handwritten decoder policy, transforms, API and CLI are .zi. The initial AV1/container decoding engine is a pinned external libavif bridge; this is not an authored AV1 decoder or a speed claim. No Kryon, window system, browser, or GUI library is required.

In progress No tagged release yet.

Add the dependency

In your project’s ziran.toml; pin ref to a commit for reproducible builds.

[dependencies.avif]
git = "https://github.com/ziranlang/avif.git"
ref = "master"

Overview

#import "avif/api"
options := DefaultOptions()
result := Decode(BorrowBytes(bytes), options)
// Check result.is_ok before using result.image, an owned std/image.Image.

From a consumer, add https://github.com/ziranlang/avif.git with ziran add. The manifest pins libavif, libaom and optional dav1d source packages, plus the av1 package with the authored AV1 decoder. Local canonical checkout overrides belong in ignored ziran.local.toml. Production lockfiles resolve committed package and toolchain revisions.

Run the package suite in this checkout:

build-queue -- sh tests/avif.sh
build-queue -- sh tests/bmff.sh

The test harness uses the canonical sibling Ziran checkout when available; otherwise set ZIRAN_ROOT to a built current toolchain. It builds a real consumer of this package, resolves its exports and requests its native artifact through ziran pkg artifact avif:native --platform linux-x86_64-gnu. Standalone module-path tests additionally verify source and saved .zir.

The stable headless command produced by the suite is:

build/bin/avif tests/fixtures/rgba8.avif build/output.rgba

It writes tight straight-alpha RGBA8 and prints dimensions, source depth, source frame count and alpha presence. Errors have stable shared error codes. See implementation and verification status, API, native recipe and fixture provenance.

avif/src/bmff.zi

bmff

Import with #import "avif/bmff".

Box :: struct { kind: u32; start: s64; payload: s64; end: s64; }

Bounded, allocation-free ISO-BMFF framing. All offsets are absolute.

BoxResult :: struct { box: Box; error: DecodeError; }
HasSignature :: (input: BorrowedBytes) -> bool

Prefix recognition only: preserve the frozen host's AvifSignature policy. The complete ftyp must be present, but following boxes need not be present or valid. Use ValidateContainer/Preflight for bounded container framing.

ReadBox :: (input: BorrowedBytes, at: s64, end: s64) -> BoxResult
ValidateContainer :: (input: BorrowedBytes) -> DecodeError

Signature policy matches the existing bridge: first box ftyp, bounded to 4096 bytes, accepting major or compatible avif/avis brands.

Preflight :: (input: BorrowedBytes, limits: DecodeLimits) -> DecodeError

Conservative container metadata scan before native allocation. No item graph interpretation or OBU extraction is claimed by this initial A-01 slice.
