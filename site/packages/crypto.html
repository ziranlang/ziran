crypto/src/sha256.zi

sha256

Ordinary library procedures retain package-qualified native symbols. A consuming executable owns any explicit C ABI it chooses to export. SHA-256 and HMAC-SHA-256, extracted from Waozi’s Daochi implementation. Portable Ziran; no foreign cryptographic implementation.

Import with #import "crypto/sha256".

Sha256Context :: struct { state: [8]u32; bit_length: u64; block: [64]u8; block_length: s32; words: [64]u32; }
Sha256RoundConstants: [64]u32
Sha256RotateRight :: (value: u32, bits: u32) -> u32
Sha256Transform :: (context: *Sha256Context)

The buffered block. Each loader reads the block's 16 big-endian words where it lies; Sha256Rounds hashes them.

Sha256TransformBlock :: (context: *Sha256Context, block: []u8)

One 64-byte block from a slice, so portable bundles can hash too.

Sha256TransformAt :: (context: *Sha256Context, block: *u8)

One 64-byte block read in place at BLOCK, for the pointer forms. Without a bounds check per byte, a package hashes as fast on phones, which build at -Oz, as it did with Daochi Client's own SHA-256.

Sha256Rounds :: (context: *Sha256Context)

The message schedule from the block's first 16 words, then the 64 rounds.

Sha256Initialize :: (context: *Sha256Context)
Sha256Update :: (context: *Sha256Context, data: *u8, length: s64)
Sha256UpdateBytes :: (context: *Sha256Context, data: []u8)

Bytes from a slice, for portable bundles; Sha256Update takes a pointer.

Sha256Finish :: (context: *Sha256Context, output: *u8)
Sha256FinishBytes :: (context: *Sha256Context, output: []u8)

The digest into a slice of 32 bytes, for portable bundles.

crypto/src/bigint.zi

bigint

Fixed-width unsigned 2048-bit Montgomery arithmetic. Sixteen-bit limbs keep every product within u64 on all native targets. Exponent bits select results with masks; both multiplications execute for every bit.

Import with #import "crypto/bigint".
