Modules / Packages

image-codec

Optional image decoder contracts and a measured RGBA8 baseline, authored in Ziran. The package reuses std/image.Image and has no Kryon or native codec dependency. AVIF, AV1 and WebP decoders are supplied by separate packages.

In progress No tagged release yet.

Add the dependency

In your project’s ziran.toml; pin ref to a commit for reproducible builds.

[dependencies.image_codec]
git = "https://github.com/ziranlang/image-codec.git"
ref = "master"

Overview

Consumers import image_codec/api when the dependency is named image_codec. Exports also expose individual ordinary modules. See API, fixtures and benchmarks.

From this canonical checkout, with Ziran at ../../ziran:

build-queue -- sh tests/contracts.sh
build-queue -- sh tests/corpus.sh --verify
build-queue -- sh tests/benchmark_contract.sh
build-queue -- sh tests/package_import.sh

ZIRAN_ROOT and ZIRAN select an existing toolchain. Tests use no display, network, fixture downloads or native codecs. Package import uses local overrides; a toolchain that requires committed HEADs rejects an unborn package. Direct module tests exercise the same source without a milestone commit. Generated outputs stay under ignored build/. The rebuilt toolchain must provide VecResize and VecResizeBounded; a version string alone does not identify this development capability before upstream integration.

image

One fallible bulk allocation. Check cancellation around allocation; pixel providers and row copies add their own checkpoints during actual work.

Caller-owned output borrows its storage. Validation and pre-cancellation precede writes; cancellation during work can leave complete rows written.
