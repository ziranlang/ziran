Lua

Lua is a Ziran package that runs Lua 5.1 code in the LuaJIT dialect. Everything is written in Ziran, with no C code and no native libraries: the lexer and parser, a compiler to register bytecode, the interpreter, a mark-and-sweep collector with weak tables and gc, and the standard libraries. It was written so that Katalis can run Luanti mods from ContentDB.

Add the dependency

In your project’s ziran.toml; pin ref to a commit for reproducible builds.

[dependencies.lua]
git = "https://github.com/ziranlang/lua.git"
ref = "master"

Overview

The embedding API follows the Lua C API: a stack, natives as plain Ziran procedures, userdata with metatables, registry references, coroutines a native can yield from, and limits on memory, call depth and instruction count for running untrusted mods. File and environment access is off until the host grants it.

Use it

ziran add https://github.com/ziranlang/lua.git

#import "lua/vm"

state: LuaState;

Add :: (L: *LuaState) -> s32 {
    a, ok1 := LuaCheckNumber(L, 1)
    if !ok1 { return LUA_NATIVE_ERROR }
    b, ok2 := LuaCheckNumber(L, 2)
    if !ok2 { return LUA_NATIVE_ERROR }
    LuaPushNumber(L, a + b)
    return 1
}

Run :: () -> bool {
    L := *state
    LuaOpen(L)
    LuaRegister(L, "add", Add)
    status := LuaDoString(L, "print(add(1, 2))", "=example")
    if status != LUA_OK {
        message, ok := LuaToString(L, -1)
        print("%\n", message)
    }
    LuaClose(L)
    return status == LUA_OK
}

docs/API.md describes the whole API and what each library supports.

Check it

make test

This runs the API unit tests, the Lua scripts in tests/lua, and loads every .lua file of the Katalis mods (set KATALIS_MODS to another folder; it is skipped when missing). make wasm (part of make test) builds the VM for wasm32 with Emscripten and runs it in a private headless Chromium; set EMCC and CHROMIUM if they are elsewhere (it is skipped without them).

vm

A Lua 5.1 virtual machine in Ziran, following the LuaJIT dialect that Luanti mods use: lexer, parser, register compiler, interpreter, garbage collector, the standard libraries (base, coroutine, string, table, math, a sandboxed os/io subset, bit, debug) and an embedding API modeled on the C API. docs/API.md documents the embedding API.
