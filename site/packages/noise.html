noise

Gradient noise for Ziran, ported from FastNoiseLite and written entirely in Ziran. Results follow FastNoiseLite's C float32 implementation, so seeds used with FastNoiseLite produce the same values.

  • Noise types: OpenSimplex2, OpenSimplex2S, Perlin, ValueCubic, Value
  • Fractals: None, FBm, Ridged, PingPong (octaves, lacunarity, gain, weighted_strength, ping_pong_strength)
  • 3D rotation: None, ImproveXYPlanes, ImproveXZPlanes

NoiseCreate() returns FastNoiseLite's defaults. Noise2D and Noise3D only read the state, so one state can be shared between threads.

fast_noise

FastNoiseLite gradient noise in pure Ziran: OpenSimplex2, OpenSimplex2S, Perlin, ValueCubic and Value, with FBm, Ridged and PingPong fractals. Ported from FastNoiseLite 1.1 (MIT, Copyright (c) 2023 Jordan Peck and contributors, see LICENSE). Every call reads the state only, so one state can be shared between threads. Results follow the C float32 implementation.

Import with #import "noise/fast_noise".
