Status / v0.7.0 and Unreleased

Current Ziran support.

Query ziran version, ziran features --json and ziran capabilities --json for the compiler you use.

Compiler pipeline

Source → ZIR → LIR → optimized LIR → ZX → native (ELF/PE, x86-64/AArch64/ARMv7). WebAssembly lowers from verified ZX. C and Go export from ZIR through zi2c and zi2go.

ziran build FILE.zi defaults to native output. Select --target=c, go, wasm or zx for another output. Linux x86-64, AArch64 and ARMv7 run ZX natively; unsupported operations report a named gap.

Safety

Safety is manual by default, as in C. --checks opts into build-wide runtime checks; #checks keeps selected bounds checks. The instruction engine always checks. See checks for coverage.

Learning

Native builds record a local corpus by default. ziran learn off stops recording. C-teacher verification and policy training run offline; benchmarks run with learning off. See learning.

References

The current support reference, module APIs, target matrix and examples describe the supported subsets. A checked program can still require an operation unavailable on a selected backend.

The latest release is 0.6.0. Master includes Unreleased work.
