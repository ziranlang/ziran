std/file

Files on every native C target under one import: Linux, Android, the web, and Windows use file_linux. It provides OpenRead, OpenWrite, OpenUpdate, OpenReplace, Read, Write, ReadAt, WriteAt, FileSize, CloseFile, RemoveFile, RenameNoReplace, PathExists, PathIsLink, DirectoryExists, CreateDirectory, CreatePrivateDirectory, OpenDirectory, NextDirectoryEntry, and CloseDirectory, plus the whole-file helpers here. ok := WriteEntireFile("notes.txt", "hello\n") text, found := ReadEntireFile("notes.txt") bytes: Vec(u8) found = ReadFileInto("notes.txt", *bytes) // freed with bytes DirectoryEntry.kind reports a snapshot of the entry's type without following links. Unknown requires a path query. Check DirectoryCursor.failed before accepting a complete walk, and always CloseDirectory even after an error.

Stable Shipped in release v0.3.1.

DeclarationsReadEntireFileReadFileIntoWriteEntireFile

Import with #import "std/file".

ReadEntireFile :: (path: string) -> (string, bool)

The whole file's bytes as text, and whether it could be read.

ReadFileInto :: (path: string, bytes: *Vec(u8)) -> bool

Appends the whole file's bytes to BYTES, which the caller owns and which is freed with the caller's local; false when the file cannot be read, and then BYTES may hold part of it. Read files that are read again and again this way: native C keeps the text ReadEntireFile returns for the life of the program.

WriteEntireFile :: (path: string, text: string) -> bool

Replace the file at PATH with TEXT; false when it cannot be written whole.
