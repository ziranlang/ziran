std/file_tree_linux

Paths, folders and whole files for native Linux tools and build programs: what a build script needs beyond file_linux's positional I/O. Paths are UTF-8 text of at most 4095 bytes. CreateDirectories("build/site/pictures") CopyTree("site", "build/site/page") names: Vec(string) if ListDirectory("levels", *names) { for names { ... } } lock := LockPath("backup/drafts/approval.lock") ReplaceFile("levels/approved.json", text) UnlockPath(lock) PathStatus reads a path's kind, owner, permission bits, size and modification time with statx, whose record has one layout on every little-endian Linux architecture.

In progress Needs: Native Linux. Added after release v0.3.1; available when building from source.

PathInfo :: struct { kind: PathKind; owner_uid: u32; mode: s32; size: s64; modified: s64; modified_nanoseconds: u32; metadata_mask: u32; identity_valid: bool; inode: u64; changed: s64; changed_nanoseconds: u32; device_major: u32; device_minor: u32; }
PathStatus :: (path: string, follow_links: bool) -> PathInfo

The path's kind, owner UID, permissions, size and modification time. A link is followed unless follow_links is false, when it reports kind Link.

A complete identity of a regular file without following its final symlink.

DIRECTORY/NAME, or NAME alone when it is absolute or DIRECTORY is empty.

PathName :: (path: string) -> string

The last part of PATH, after its final slash.

PathParent :: (path: string) -> string

PATH without its last part: "." for a bare name, "/" for a root entry.

PathSuffix :: (path: string) -> string

The name's extension with its dot, as Python's Path.suffix: ".png".

PathStem :: (path: string) -> string

The name without its extension, as Python's Path.stem.

ResolvePath :: (path: string) -> Text

The absolute path with every link and dot resolved; empty when PATH does not exist.

CreateTemporaryDirectory :: (parent: string, prefix: string) -> Text

Atomically creates a unique private child of an existing caller-owned parent. The parent and its ancestors must stay at stable paths during the call. PREFIX is a single name component; six random characters follow it. Returns the canonical absolute child path, or empty on failure. The caller owns the returned allocation and directory cleanup with RemoveTree. Permissions are 0700, restricted by umask.

WorkingDirectory :: () -> Text
CreateDirectories :: (path: string, mode: s32) -> bool

Creates PATH and every missing parent folder; true when it exists as a folder afterwards.

ListDirectory :: (path: string, names: *Vec(string)) -> bool

The names in a folder, without "." and "..", sorted by their bytes. Appends independently owned entry names in sorted order. The caller owns each nonempty string as well as the Vec; failed scans append nothing.

RemoveTree :: (path: string) -> bool

Removes PATH and, for a folder, everything in it. Links are removed, never followed. True when nothing remains at PATH. All traversal scratch is freed.

CopyFile :: (source: string, target: string) -> bool

Copies a file's bytes and permission bits to TARGET, replacing it.

CopyTree :: (source: string, target: string) -> bool

Copies a folder and everything in it to TARGET, which is created; links inside are copied as links.

ReplaceFile :: (path: string, text: string) -> bool

Replaces the file at PATH with TEXT so that readers see either the old or the new whole file: a private sibling file is written, synced and renamed over it. The new file keeps the old one's permission bits.

LockPath :: (path: string, exclusive: bool, wait: bool) -> s32

Opens (creating) the lock file at PATH and takes its flock: exclusive or shared, waiting or not. Returns the descriptor to UnlockPath, or -1 when the file cannot be opened or, without wait, another holder has it.

UnlockPath :: (fd: s32)
MatchName :: (name: string, pattern: string) -> bool

Whether NAME matches a shell wildcard PATTERN: * any run, ? one byte, [abc], [a-z] and [!abc] one byte of a set. Nothing else is special.
