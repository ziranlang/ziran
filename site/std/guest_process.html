Modules / Standard library

std/guest_process

Process operations supplied by the native runner. Argument 0 is the bundle's path; `zx app.zx a b` gives the bundle three arguments.

Stable Needs: Host capability. Shipped in release v0.9.0.

DeclarationsArgumentCountArgumentEnvironmentProcessIdClockTicksPageSizeSendSignalRunShell

Import with #import "std/guest_process".

ArgumentCount :: () -> s32

Needs a host capability.

Argument :: (index: s32) -> string

The argument at index, or "" outside 0..ArgumentCount() - 1.

Needs a host capability.

Environment :: (name: string) -> string

The variable's value, or "" when it is unset.

Needs a host capability.

ProcessId :: () -> s32

The native process hosting this bundle, suitable for excluding itself from a process list. These operations require a host that provides them.

Needs a host capability.

ClockTicks :: () -> s64

Native accounting ticks per second and bytes per memory page. A nonpositive value means the host could not obtain the unit; callers must not invent one.

Needs a host capability.

PageSize :: () -> s64

Needs a host capability.

SendSignal :: (process_id: s32, signal: s32) -> bool

Native signal semantics, including signal 0 to check an owned process.

Needs a host capability.

RunShell :: (command: string) -> s32

Runs a native shell command synchronously and returns its native wait status, or -1 if it could not run. Embedded NUL bytes are rejected, never truncated.

Needs a host capability.
