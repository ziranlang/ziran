std/gzip_linux

Bounded native gzip over the platform zlib. Works on the same C targets as zip_linux, including Android, Windows and Emscripten. Link the platform zlib.

In progress Needs: Native Linux. Added after release v0.3.1; available when building from source.

DeclarationsGzipBoundGzipCompressGzipDecompress

Import with #import "std/gzip_linux".

GzipBound :: (count: s64) -> s64
GzipCompress :: (input: []u8, output: []u8, level: s32) -> s64

Returns the number of binary bytes written, or -1. Input and output must not overlap. Buffers and platform stream allocation remain bounded.

GzipDecompress :: (input: []u8, output: []u8, expected_size: s64) -> bool

Exactly one complete gzip stream, with its CRC and size verified. Reject trailing bytes, concatenated members and any expansion beyond expected_size.
