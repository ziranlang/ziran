std/hash_map

A hash map from keys to values that runs the same on every target and the portable runner. Keys are strings or integers. The table doubles when half its slots are in use, and HashMapFree releases it. ages: HashMap(string, s32) HashMapSet(*ages, "ada", 36) age: s32 if HashMapGet(*ages, "ada", *age) { print("%\n", age) } HashMapFree(*ages)

Stable Shipped in release v0.3.1.
