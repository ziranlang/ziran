std/hmac_sha256_go

Stable Needs: Go target. Shipped in release v0.3.1.

DeclarationsDigestResultHMACSHA256

Import with #import "std/hmac_sha256_go".

DigestResult :: struct { value: string; error: string; }
HMACSHA256 :: (key: []u8, message: string) -> DigestResult

HMAC over arbitrary text bytes. SHA-256 itself comes from Go's crypto package; this module owns only RFC 2104's key normalization and pads.
