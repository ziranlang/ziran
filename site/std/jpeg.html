std/jpeg

Baseline JPEG files from std/image pictures, on every target: JFIF with 4:2:0 chroma subsampling, the standard Huffman tables and the IJG quality scale that libjpeg and Pillow use. Alpha is ignored. bytes: Vec(u8) if WriteJPEG(*title, *bytes, 82) { WriteEntireFile("title.jpg", BuilderFinish(bytes)) }

In progress Added after release v0.3.1; available when building from source.

DeclarationsWriteJPEG

Import with #import "std/jpeg".

WriteJPEG :: (image: *Image, output: *Vec(u8), quality: s32) -> bool

Appends IMAGE as a baseline JPEG at QUALITY (1 to 100) to OUTPUT.
