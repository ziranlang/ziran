std/json_document

JSON documents read into a tree that programs query, change and write back. Nodes live in the document's vector and are named by their index; -1 names no node, and every query accepts it. document: JsonDocument if !JsonRead(*document, text) { print("%\n", document.error) } levels := JsonMember(*document, document.root, "levels") level := JsonFirst(*document, levels) while level >= 0 { number, ok := JsonInteger(*document, JsonMember(*document, level, "number")) level = JsonNext(*document, level) } JsonSet(*document, document.root, "count", JsonNewInteger(*document, 3)) saved := JsonWrite(*document, document.root, JsonPythonStyle(1)) JsonWrite lays text out as Python's json.dumps does for the same style: separators, indentation, empty containers, ensure_ascii escapes and sort_keys. Numbers keep the text they were read with unless python_floats is enabled in the style. Strings without escapes are views of the text that was read, so keep that text alive while the document is used. Objects keep every member in order; a repeated name is answered by its last member, as Python's dict reads it.

In progress Added after release v0.3.1; available when building from source.

JsonNode :: struct { kind: JsonKind; text: string; owned_text: Vec(u8); key: string; owned_key: Vec(u8); first: s32; last: s32; next: s32; count: s32; }
JsonDocument :: struct { nodes: Vec(JsonNode); root: s32; error: string; error_at: s64; erase: JsonEraser; erase_context: *void; }
JsonStyle :: struct { indent: s32; item_separator: string; key_separator: string; ascii: bool; sort_keys: bool; python_floats: bool; }
JsonPythonStyle :: (indent: s32, ascii: bool, sort_keys: bool, python_floats: bool) -> JsonStyle

The style of Python's json.dumps(value, indent=INDENT); a negative INDENT stands for indent=None. ASCII escapes are on, as ensure_ascii's default.

JsonCompactStyle :: (ascii: bool, sort_keys: bool) -> JsonStyle

One line with separators=(',', ':').

JsonSetEraser :: (document: *JsonDocument, erase: JsonEraser, context: *void)

Register an optional owner-supplied eraser before building/copying private text. It receives actual owned bytes, including failed partial strings. Call JsonReset before the document leaves scope; borrowed source bytes stay the caller's responsibility. No cryptographic dependency lives in JSON.

JsonReset :: (document: *JsonDocument)
JsonRead :: (document: *JsonDocument, text: string, erase: JsonEraser, erase_context: *void) -> bool

Reads TEXT as the document's root, after clearing it. False, with error and error_at set, when TEXT is not one complete JSON value.

JsonAppend :: (document: *JsonDocument, array: s32, child: s32) -> bool

Adds CHILD, a node not yet in any container, to the end of ARRAY.

JsonSet :: (document: *JsonDocument, object: s32, key: string, child: s32) -> bool

Sets OBJECT's member KEY to CHILD, a node not yet in any container: a present member is replaced where it stands, as a Python dict keeps its place, and a new one goes last.

JsonSetCopy :: (document: *JsonDocument, object: s32, key: string, child: s32) -> bool

Like JsonSet, with a document-owned copy of KEY. Use this when the caller's key storage will be released before the document is written.

JsonRemove :: (document: *JsonDocument, object: s32, key: string) -> bool

Removes every member named KEY; false when there was none.

JsonClear :: (document: *JsonDocument, node: s32)

Empties an array or object.

JsonCopy :: (target: *JsonDocument, source: *JsonDocument, node: s32) -> s32

A deep copy of SOURCE's NODE as a new node of TARGET, which may be the same document; returns it, or -1 for a missing node.

JsonQuoteInto :: (output: *Vec(u8), value: string, ascii: bool) -> bool

Appends VALUE as a quoted JSON string, escaped as json.dumps escapes it.

JsonQuote :: (value: string, ascii: bool) -> string
JsonWrite :: (document: *JsonDocument, node: s32, style: JsonStyle) -> string

NODE and everything in it as JSON text in STYLE, without a final newline.

JsonWriteInto :: (output: *Vec(u8), document: *JsonDocument, node: s32, style: JsonStyle) -> bool

Append to caller-owned storage. It must not back this document's borrowed input, or be one of its owned node buffers. Discard partial output on error. Sensitive callers start with empty/wiped storage or pre-reserve its lifetime maximum; they erase their own output and borrowed input after use.
