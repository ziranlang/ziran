SendCurl :: (request: HttpRequest, output: []u8) -> CurlResult

The caller owns output. It remains NUL terminated, including on failure. HTTP errors retain their status and body for protocol-level decisions.

SendCurlWithin :: (request: HttpRequest, output: []u8, timeout_ms: s32) -> CurlResult

The same request with its own total timeout, for slow services such as model generation. Connecting still has 10 seconds.

SendCurlDirectWithin :: (request: HttpRequest, output: []u8, timeout_ms: s32) -> CurlResult

Bypass inherited proxy settings and never follow redirects. Callers still own URL authorization; this is useful for private local service transports.
