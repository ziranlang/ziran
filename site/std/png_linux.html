std/png_linux

PNG files to and from std/image pictures on native Linux, over the platform zlib (link -lz). sprite := ReadPNGFile("sprites/tile-12.png") if !ImageValid(*sprite) { ... } WritePNGFile("build/tile.png", *sprite) WriteIndexedPNGFile("build/level.png", *QuantizeImage(*board, 192, true)) Reading accepts every standard PNG: greyscale, RGB, palette, grey with alpha and RGBA at any bit depth, tRNS transparency and Adam7 interlacing; 16-bit samples keep their high byte. Writing uses Pillow's choices for an optimized file: zlib level 9, adaptive row filters for RGB and RGBA, none for palette pictures.

In progress Needs: Native Linux. Added after release v0.3.1; available when building from source.

Import with #import "std/png_linux".

ReadPNG :: (bytes: []u8) -> Image

The picture a whole PNG file's bytes hold; an invalid Image (see ImageValid) when they are not a PNG this reads.

WritePNG :: (image: *Image, output: *Vec(u8), alpha: bool, level: s32) -> bool

Encodes IMAGE as RGBA, or as RGB when ALPHA is false, appending the file's bytes to OUTPUT.

WriteIndexedPNG :: (image: *IndexedImage, output: *Vec(u8), level: s32) -> bool

Encodes a palette picture with 8-bit indices, appending the file's bytes to OUTPUT.

ReadPNGFile :: (path: string) -> Image

The picture in a PNG file; invalid when it cannot be read.
