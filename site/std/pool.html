std/pool

Generational slot pool backed by Vec storage and a free list so cyclic and reference-graph structures can be represented safely without a garbage collector. Live slots always carry generation >= 1, so a zero-initialized PoolHandle is never valid.

In progress Available on master (Unreleased).
