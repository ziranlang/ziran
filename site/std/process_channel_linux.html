Modules / Standard library

std/process_channel_linux

An owned native child with bidirectional byte I/O. Arguments pass directly to execvp, and each child has its own process group. Do not copy a live channel: one owner must join it before releasing its storage. The explicit argv contains 1 through 32 arguments, each at most 4095 non-NUL bytes.

Stable Needs: Native Linux. Shipped in release v0.4.2.

End this child's input without closing its output. The caller may continue ChannelReceive and must still WaitChannel/CloseChannel. A second half-close is harmless while the channel remains open. Further sends safely fail.

ChannelReceive :: (channel: ProcessChannel, output: []u8, timeout_ms: s32) -> s64
WaitChannel :: (channel: *ProcessChannel, timeout_ms: s32) -> bool
CloseChannel :: (channel: *ProcessChannel, timeout_ms: s32) -> bool
CancelChannel :: (channel: *ProcessChannel) -> bool

Cancellation keeps the unreaped PID as proof of process-group ownership. Signal the group before WaitChannel can reap an already-exited parent whose descendant still owns stdout. Already joined channels only close their fd.
