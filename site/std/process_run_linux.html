std/process_run_linux

Run native Linux child processes from build and release programs: any number of arguments, a working directory, environment changes, and each standard stream inherited, discarded, read from or written to a file, or captured. No shell parses anything; the first argument is looked up on PATH as execvp does. command: [3]string = .["git", "rev-parse", "HEAD"] options: ProcessOptions = .{arguments = command[:], capture_output = true} run: ProcessRun if RunProcess(options, *run) && run.code == 0 { revision := BuilderFinish(run.output) } StartProcess leaves the child running; PollProcess, WaitProcess and SignalProcess follow it. A child that cannot be started (a missing program or directory, an unreadable input file) reports started = false and code 127 instead of running anything. Programs that start children should stay single-threaded: the child applies its working directory and environment between fork and exec.

In progress Needs: Native Linux. Added after release v0.3.1; available when building from source.

ProcessArgumentSlot :: struct { value: *u8; }
ProcessOptions :: struct { arguments: []string; directory: string; environment: []string; input_path: string; output_path: string; append_output: bool; error_path: string; merge_error: bool; capture_output: bool; new_session: bool; }
ProcessRun :: struct { pid: s32; code: s32; started: bool; finished: bool; output: Vec(u8); }
StartProcess :: (options: ProcessOptions, run: *ProcessRun) -> bool

Starts the child and leaves it running; capture_output is not available here, so a captured stream goes to output_path instead.

PollProcess :: (run: *ProcessRun) -> bool

Whether the child has finished, without waiting; its code is then set.

WaitProcess :: (run: *ProcessRun) -> bool

Waits for the child to finish and sets its code.

SignalProcess :: (run: *ProcessRun, signal_number: s32, whole_group: bool) -> bool

Sends a signal (15 asks to stop, 9 kills) to the child, or with whole_group to the process group a new_session child leads.

RunProcess :: (options: ProcessOptions, run: *ProcessRun) -> bool

Runs the child to completion. With capture_output its standard output is appended to run.output. False when it could not be started or waited for.

CatchTermination :: ()

After this, SIGTERM and SIGINT set TerminationRequested instead of ending the program, so it can stop its own children and clean up.

TerminationRequested :: () -> bool
