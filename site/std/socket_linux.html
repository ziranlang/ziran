std/socket_linux

Bounded, cancellation-aware TCP client sockets for native Linux programs. The caller supplies a literal IPv4 address; this module performs no DNS, HTTP, TLS, or plaintext-protocol fallback.

Stable Needs: Native Linux. Shipped in release v0.3.1.
