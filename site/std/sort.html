std/sort

Sorting and searching for slices of any type ordered by the < operator. Sorting is an in-place heapsort: O(n log n) comparisons, no allocation, no recursion, and not stable.

Stable Shipped in release v0.3.1.

LowerBound :: (values: []$T, target: T) -> s64

Returns the first index whose value is not less than target, or values.count when every value is less. values must be sorted.

BinarySearch :: (values: []$T, target: T) -> s64

Returns an index holding target, or -1 when values has none. values must be sorted.
