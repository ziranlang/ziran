std/stdio_linux

The standard streams of a native Linux program: text to standard output or standard error, and the whole of standard input. if !ok { PrintError("levels/approved.json is missing\n"); return 1 } input := ReadStandardInput()

Stable Needs: Native Linux. Shipped in release v0.4.2.

DeclarationsWriteOutputPrintErrorReadStandardInput

Import with #import "std/stdio_linux".

WriteOutput :: (text: string) -> bool

Writes TEXT to standard output, unbuffered; false when it could not.

PrintError :: (text: string) -> bool

Writes TEXT to standard error; false when it could not.

ReadStandardInput :: () -> Text

Everything on standard input until its end.
