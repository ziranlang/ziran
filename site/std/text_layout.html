std/text_layout

Font- and renderer-independent UTF-8 text layout. All ranges borrow the input; the caller measures complete runs, preserving shaping and bidi context. No windows, host calls, allocation, global state or measurement cache.

In progress Available on master (Unreleased).

Ideographic :: (point: u32) -> bool

Japanese and Chinese are written without spaces, so a line may break between their characters. Kana, ideographs, and the fullwidth forms count; Hangul is spaced and breaks at its spaces.

NoBreakBefore :: (point: u32) -> bool

Closing punctuation, the prolonged sound mark, and small kana never start a line.

NoBreakAfter :: (point: u32) -> bool

Opening brackets never end a line.

BreaksBetween :: (before: u32, after: u32) -> bool

Whether a line may break between two adjacent characters of one word.

NextToken :: (value: string, offset: s32, marker: string) -> Token

Whitespace and line breaks delimit borrowed UTF-8 byte ranges, and so do the places between characters where spaceless text may wrap. An optional caller-defined marker is returned as a separate token.

NextCluster :: (value: string, offset: s32) -> s32
NextLine :: (value: string, start: s32, max_width: float32, wrap: Wrap, measure: $M, context: $T) -> Line

Auto keeps oversized words intact. Anywhere accepts at least one whole grapheme. None and Ellipsis plan unwrapped lines; the caller paints ellipses. Bind measure to its procedure type; context keeps its concrete caller type.

CharactersEnd :: (value: string, count: s32) -> s32

The byte offset just after the first count characters of value. A character is a grapheme cluster, so typed text never splits an accent, an emoji or a multibyte letter. No characters end at 0; a count past the last character ends at the whole text.
