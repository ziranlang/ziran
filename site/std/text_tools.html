std/text_tools

Searching, splitting and rewriting text for tools and build programs. Every operation works on bytes, so it is exact for UTF-8 text and needs no platform library. Results that are pieces of the input (TextTrim, TextSplit, TextLines) are views of it; TextReplace and TextJoin build new text. for TextLines(changelog) { if TextHasPrefix(it, "## [") { version_line = it; break } }

In progress Added after release v0.3.1; available when building from source.

The lines of TEXT without their line endings (\n, \r\n or \r); a final line ending adds no empty line.

TextHexDecodeInto :: (value: string, output: *Vec(u8), max_bytes: s64) -> bool

Decodes VALUE's uppercase or lowercase hexadecimal bytes and appends them to OUTPUT. MAX_BYTES bounds the bytes this call appends; false leaves OUTPUT unchanged on any failure, including an odd length, an invalid digit, an exceeded limit, or an allocation failure.
