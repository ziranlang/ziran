std/thread_linux

Background work for native Linux, Android and macOS programs. A thread runs one procedure while the thread that started it keeps going, and that thread can ask whether the work has finished without waiting, so a frame loop keeps drawing while a request is in flight. A Thread record must stay at one address from ThreadStart until ThreadFinished or ThreadWait reports the end. Once it has, everything the procedure wrote is visible to the thread that asked, and the record can start another procedure.

Stable Needs: Native Linux. Shipped in release v0.3.1.

Starts `procedure(argument)` on a new thread. Returns false when the record is still running something or no thread could be started. `notification.procedure(notification.argument)` runs once after completion is published, so an event loop can wake without polling. It must not join or restart this Thread. Both arguments must live until the owner joins it.

ThreadRunning :: (thread: *Thread) -> bool

Whether the record is running a procedure that has not been reported finished yet.

ThreadFinished :: (thread: *Thread) -> bool

Whether the procedure started on `thread` has finished. Never waits; the first time it reports true the thread is joined and the record is free.

ThreadWait :: (thread: *Thread)

Waits until the procedure started on `thread` has finished.
