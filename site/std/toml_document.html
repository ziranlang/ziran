std/toml_document

TOML 1.0 documents. Pure Ziran: no filesystem, subprocess, or interpreter. Nodes are indexed; -1 is missing. Queries accept missing nodes. Text views borrow the input, so keep it alive until the document is discarded/reused.

In progress Added after release v0.3.1; available when building from source.

TomlRead :: (document: *TomlDocument, text: string, max_bytes: s64) -> bool

Parse the complete UTF-8 document, bounded before allocation. On failure no partial tree is exposed (root = -1); error/error_at describe the first error. Increase max_bytes explicitly for larger documents. Depth is bounded at 128.
