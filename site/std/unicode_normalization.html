std/unicode_normalization

Canonical Unicode 17.0 NFC. Portable C/Go/VM; no platform Unicode library.

In progress Added after release v0.3.1; available when building from source.

DeclarationsPropertiesNFCInto

Import with #import "std/unicode_normalization".

Properties :: (point: u32) -> s32
NFCInto :: (text: string, output: *Vec(u8)) -> bool

Replace output with NFC bytes. Input must be valid UTF-8 and must not borrow output. On any invalid input/allocation failure output is empty; capacity may be retained. Empty input succeeds. Caller owns output, with no size cap beyond Vec's checked element/byte representability and available allocation.
