std/vorbis

What an Ogg Vorbis stream held in memory declares, read from its pages alone: nothing is decoded or allocated, so a program can bound a stream before handing it to a decoder (std/vorbis_linux on Linux, or another platform's). Portable: no foreign library. audio: VorbisAudio if VorbisProbe(ogg_bytes, *audio) && audio.channels == 1 { ... }

In progress Added after release v0.3.1; available when building from source.

DeclarationsVorbisAudioVorbisProbe

Import with #import "std/vorbis".

VorbisAudio :: struct { channels: s32; rate: s32; frames: s64; }

Interleaved CHANNELS at RATE, FRAMES long.

VorbisProbe :: (input: []u8, audio: *VorbisAudio) -> bool

Whether INPUT is exactly one Ogg Vorbis stream: whole pages of a single logical stream and nothing else, beginning with its first page, ending with its last, and starting with a Vorbis identification header. AUDIO then holds its channels, rate and length, the last page's granule position (streams start at zero, as encoders write them). Page CRCs are left to the decoder. AUDIO is zero when the answer is false.
