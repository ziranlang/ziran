std/vorbis_linux

Whole Ogg Vorbis streams held in memory, decoded over the platform libvorbisfile into signed 16-bit little-endian PCM. std/vorbis checks the stream's pages and length first, before the library allocates anything. Only programs that import this module need the library; link it with -lvorbisfile, or with -l:libvorbisfile.so.3 where only the runtime package is installed. pcm: Vec(u8) audio: VorbisAudio if VorbisDecode(ogg_bytes, *pcm, 22050 * 60, *audio) { ... } The records below mirror the public declarations in libogg's ogg.h and libvorbis's codec.h and vorbisfile.h field for field, so the C compiler lays them out exactly as the library does. Every decode also checks a guard placed after its OggVorbis_File, so a library that wrote past the mirror fails the decode instead of passing unnoticed.

In progress Needs: Native Linux. Added after release v0.3.1; available when building from source.

OggVorbis_File.

VorbisDecode :: (input: []u8, output: *Vec(u8), max_frames: s64, audio: *VorbisAudio) -> bool

Replaces OUTPUT with the decoded samples of the single Ogg Vorbis stream INPUT holds: interleaved, signed 16-bit little-endian. False, with OUTPUT empty, for anything else: an empty, damaged or truncated stream, trailing bytes, chained streams, a stream whose decoded length differs from its declared length, or one longer than MAX_FRAMES frames.
