std/web

Browser access for Ziran code compiled to WebAssembly. Any Web API is reachable through objects held in the page's handle table: read and write properties, call methods, construct objects, pass Ziran functions as callbacks, and wait on promises. The page side is web/ziran_web.js. A handle is an s32; 0 means null or undefined, 1 is the global object, and 2 is Emscripten's Module. Names are interned once with WebName and reused, which keeps each call cheap. Handles the bridge returns are temporary: they all die when the current scope ends. A callback is its own scope; a long-running loop should wrap each pass in WebScope and WebEnd. WebKeep turns a temporary handle into one that lasts until WebRelease, for objects a program holds on to.

Stable Shipped in release v0.3.1.

WebBlobBytes :: (data: *void, count: s32) -> s32

A Blob snapshot of `count` bytes from `data`, or 0 for an invalid range. The browser snapshots the Wasm view within this one host call: callers may change/free the source or grow memory as soon as this returns. This avoids the extra encoded-byte copy of WebBytes followed by a Blob constructor. Useful for files, downloads, media and request bodies; MIME may be supplied later with the ordinary Blob.slice API. WebBytes keeps its copy semantics.
