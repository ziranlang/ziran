Measured, with context

Know what the numbers mean.

All four targets reproduce the independently checked return value or printed output of each source. Compare target behavior and costs on these small programs; the figures describe this run and its host.

Execution

Median warm time per entry after at least 150 ms of warmup and calibrated batches. Loading, startup, downloads and offline compilation are excluded. Output is verified before timing; formatting and runtime-specific output to a null sink or browser callback remain included. Tiny programs emphasize call and I/O overhead.

Emission

Loading, checking, linking and writing the selected output on the desktop build host. C uses cc -O2 and Go uses go build afterward; those downstream build costs are excluded from emission. ZIR is inspected, not executed.

Size & coverage

Size means emitted files, including C headers and imported modules, rather than linked executable size. ZX uses the portable VM on every platform. WebAssembly runs in V8 on desktop and web, and WAMR AOT on the USB Android phone. Web C uses Emscripten; web Go uses its js/wasm runtime.

The snapshot includes the host, compiler hashes, revision, tool versions and every sample.
