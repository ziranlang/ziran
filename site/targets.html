Measurement method

All four targets reproduce the independently checked return value or printed output of each source. Compare target behavior and costs on these small programs; the figures describe this run and its host.

Execution

Median warm time after 150 ms of warmup and calibrated batches, excluding symmetric 1.5×IQR outliers. Raw samples and exclusions remain downloadable. Loading, startup, downloads and offline compilation are excluded. Output is verified before timing; formatting and runtime-specific output to a null sink or browser callback remain included. Tiny programs emphasize call and I/O overhead.

Emission

Loading, checking, linking and writing the selected output on the desktop build host. C uses cc -O2 and Go uses go build afterward; those downstream build costs are excluded from emission. ZIR is inspected, not executed.

Size & coverage

Size counts emitted files, including C headers and imported modules. The examples run with native ZX and WebAssembly in V8. The inspector still shows the portable ZX bundle and the generated Wasm module.
