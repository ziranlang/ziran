Know what the numbers mean.

All successful targets return the same independently checked answer for each source. Compare target behavior and costs on these small programs; the figures describe this run and its host.

Execution

Median whole-process time after one discarded warmup, with shuffled execution order. Includes process startup and output. WebAssembly also includes Node startup, engine compilation and instantiation. This is not steady-state kernel timing.

Emission

Loading, checking, linking and writing the selected output. C uses cc -O2 and Go uses go build afterward; those downstream build costs are excluded from emission. ZIR is inspected, not executed.

Size & coverage

Size means emitted files, including C headers and imported modules, rather than linked executable size. ZX timings explicitly use --vm. Unsupported WebAssembly cells show the real compiler diagnostic.

The snapshot includes the host, compiler hashes, revision, tool versions and every sample.
